# MIRBIT

Visor de cámaras Dahua ultraliviano para Windows (Windows 10 y Windows 11, 32 y 64 bits).

## Descarga e Instalación

Descargue el instalador auto-contenido desde la sección de [**Releases**](https://github.com/Neo236/mirbit/releases/latest):

- **`InstalarMIRBIT.exe`** (ejecutable único para Windows de 32 y 64 bits, no requiere permisos de administrador).

### Características
- **Vista limpia**: Nombres de cámaras ocultos por defecto para aprovechar el 100 % de cada celda (se pueden mostrar u ocultar con clic derecho o presionando la tecla `N`).
- **Consumo mínimo**: Pausa automática de decodificación al minimizar la ventana (~0 % de CPU) y reanudación instantánea al restaurar.
- **Reconexión automática**: Recuperación transparente ante cortes de red o reinicios del grabador.
- **Seguridad local**: Contraseña cifrada en el equipo mediante Windows DPAPI.
